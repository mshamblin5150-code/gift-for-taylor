# Help follows reader roles and tasks

Help is an offline, searchable guide for people using the app during ordinary work. It has two audiences: Staff members, and the people scheduling or administering their work (Manager, Night scheduler and Administrator). The latter audience can also read Staff guidance so they can answer Staff questions. Topics for actions only the Manager can perform remain visible to the other schedulers, but must say clearly that the action is Manager-only. This shared reference was chosen over three separate catalogs, which would repeat guidance and drift apart.

A topic starts with the immediate answer, then gives clear, ordered steps and the expected result. Add a reason or an "If it goes wrong" section only when it helps the reader complete the task. Simple topics stay brief; complex workflows get enough context to be understood. There is no universal word ceiling: an independent agent reviews each topic against a realistic question a reader would bring to Help. The reader should be able to find the topic and complete the task from it without guessing. The review checks familiar words, one action per step, explained app terms when needed, and a clear result. This task check was chosen over a reading-grade score or uniform topic length because neither shows whether the instructions work.

The voice is direct, calm and practical, with fuller reasoning where it prevents confusion. The rewrite first produces one simple Staff topic and one complex Manager topic for Matt to review for voice before the remaining topics are written. It audits user-facing tasks, adding or splitting topics where an answer is missing or muddled. Help stays bundled with the app for offline use and searchable in the reader's own terms. Every user-facing behavior change updates the affected Help guidance and search terms in the same change.
